# Architecture

The CLI parses commands and formats results. The core owns discovery, a JSON manifest, locking and export planning; `FaceService` is the sole MediaIntelligence adapter. The analyzer exclusively manages its directory. Asset UUIDs are persisted before submission and reused on retries; successful metadata is committed after each image. Failed or interrupted submissions are retried, and stale grouping is resumed before listing or exporting. Files are submitted individually to bound memory and isolate errors. A size/mtime comparison is a heuristic, not a content integrity guarantee.

Export plans deduplicate per group, use encoded native entity IDs for safe directory names, and disambiguate collisions. Preview does not write exports. Copy and symlink operations use Foundation's non-overwriting creation operations. The library lock is advisory and protects cooperating CLI processes, not external changes to files or destinations. Filesystem changes by other processes between preview and application can cause an error or partial export.

Apple documents on-device processing and the analyzer APIs at [FaceGroupAnalyzer](https://developer.apple.com/documentation/mediaintelligence/facegroupanalyzer) and [Detecting and grouping faces in images](https://developer.apple.com/documentation/mediaintelligence/detecting-and-grouping-faces-in-images). No claims are made about cluster stability or accuracy. The manifest is not an identity database; no removal or reset commands are exposed.
