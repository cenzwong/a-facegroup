# Architecture

The CLI parses commands and formats results. The core owns discovery, a JSON manifest, locking and export planning; `FaceService` is the sole MediaIntelligence adapter. The analyzer exclusively manages its directory. Asset UUIDs are persisted before submission and reused on retries; successful metadata is committed after each image. Failed or interrupted submissions are retried, and stale grouping is resumed before listing or exporting. Files are submitted individually to bound memory and isolate errors. A size/mtime comparison is a heuristic, not a content integrity guarantee.

Export plans deduplicate per group, use encoded native entity IDs for safe directory names, disambiguate collisions, and reject missing or changed source metadata before writing. This check shares the size/mtime heuristic and is not a content hash. Preview does not write exports. Copy and symlink operations use Foundation's non-overwriting creation operations. The library lock is advisory and protects cooperating CLI processes, not external changes to files or destinations. Filesystem changes by other processes between preview and application can cause an error or partial export.

Apple documents on-device processing and the analyzer APIs at [FaceGroupAnalyzer](https://developer.apple.com/documentation/mediaintelligence/facegroupanalyzer) and [Detecting and grouping faces in images](https://developer.apple.com/documentation/mediaintelligence/detecting-and-grouping-faces-in-images). No claims are made about cluster stability or accuracy. The manifest is not an identity database; no removal or reset commands are exposed.

A native smoke test used the [scikit-image astronaut sample](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut), described there as a public-domain NASA photograph. It is fetched separately and is not bundled. Failed or interrupted assets remain pending for retry and are omitted from people and export results until successfully indexed; successful assets remain available. MediaIntelligence can print face details to stdout, so the CLI discards its framework stdout before writing its own results.

The multi-person integration check was run with a temporary composite of the scikit-image portrait and NASA's [Alan Shepard portrait](https://commons.wikimedia.org/wiki/File:Alan_Shepard_in_1960.jpg), described as public domain on its source page. The same check also passed on the unmodified [STS-114 crew photograph](https://commons.wikimedia.org/wiki/File:STS-114_crew.jpg) (SHA-256 `079a507163ec5d901261400c7cf177a5e92efefff05087005af6e19738e1bce2`). These checks verify routing of one image to multiple folders; they do not establish recognition accuracy.
